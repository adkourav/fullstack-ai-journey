## What is variable in java ? ##

# Ans :- #

A variable in Java is a named memory location used to store a value that can be changed during the execution of a program. 



Simple interview definition:

A variable is a name given to a memory location that stores a value.

Example:
int age = 22;
String name = "Adarsh";


Here:

age → variable
22 → value stored in the variable
int → data type of the variable

In simple words:
👉 A variable is like a box with a name where we store data.
