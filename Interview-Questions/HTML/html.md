## QUE 1 :-  What is semantic HTML and why does it matter (SEO + accessibility)?

# ANS :- #

Semantic HTML means using HTML tags that tell us what the content is and what it does.

For example:

 ## header ## 
 → Top/header part of the webpage
 ## nav ## 
 → Navigation links
 ## main #  
 → Main content of the webpage
# article # 
→ An article or independent content
 # footer # 
 → Bottom/footer part of the webpage

Semantic HTML is useful for SEO because it helps search engines like Google understand the structure of our webpage.

It is also useful for Accessibility because screen readers can understand the different parts of the webpage and help users navigate them.

## What is SEO ? 

## ANS :- ##

SEO stand for search engine optimization 


## Example :- ##

<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="/">Home</a>
  <a href="/about">About</a>
</nav>

<main>
  <h2>About Me</h2>
  <p>I am learning HTML.</p>
</main>

<footer>
  <p>Copyright 2026</p>
</footer>


👉 Easy to remember:-


Semantic HTML = HTML tags with clear meaning → Better SEO + Better Accessibility.


## What is <iframe> in HTML? ##

# Ans:- #
<iframe> stands for Inline Frame.

It is used to display another webpage, video, map, document, or other external content inside your current HTML webpage.


## Simple definition

<iframe> is an HTML element used to embed external content inside a webpage.

Basic Syntax
<iframe src="URL"></iframe>

Here:

iframe → creates a frame
src → specifies what content should be displayed
