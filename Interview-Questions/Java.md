## Que. 1 :-  What is the difference between JDK, JRE and JVM? ##

# Ans :- #

1. ## JDK (Java Development Kit ):- ##
    
    It provides everything needed to Develop and Run jave Programs . It contains the JRE and JVM , and the Development Tools like Java Compiler 

2. ## JRE (Java Runtime Environment ) :- ##
    
    It provides the Environmet Needed to run Jave Programs .
    It contain the JVM and Required Libraries . 

3. ## JVM (Java Virtual Machine ) :- ##
    
    It runs a Java bytecode and makes java plateform - Independent . 


## Easy way to remember

JDK → JRE → JVM

## In short:

JDK = Develop + Run

JRE = Run

JVM = Execute Java bytecode

 Interview tip: If the interviewer asks for the main difference, simply remember: JDK is for development, JRE is for running, and JVM actually executes the Java bytecode.
