# Java Operators - Quick Revision

## Definition
An operator is a symbol used to perform an operation on one or more values or variables.

## Types of Operators

| Type | Meaning | Examples |
|------|---------|----------|
| Arithmetic | Performs mathematical calculations | `+`, `-`, `*`, `/`, `%` |
| Relational | Compares values | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| Logical | Combines conditions | `&&`, `||`, `!` |
| Assignment | Assigns values | `=`, `+=`, `-=`, `*=`, `/=` |
| Unary | Works with one operand | `++`, `--`, `!` |
| Bitwise | Works on bits | `&`, `|`, `^`, `~` |
| Shift | Shifts bits left/right | `<<`, `>>`, `>>>` |
| Ternary | Short form of if-else | `condition ? value1 : value2` |

## Use Cases
- Calculate marks
- Compare age
- Check multiple conditions
- Assign or update values
- Make decisions

## Syntax Examples
- `a + b`
- `a > b`
- `a && b`
- `condition ? value1 : value2`

## Real-Life Example
If `age >= 18`, a person can vote.

Example:
- `age >= 18`

## Quick Revision
- Operator = Performs an operation
- Calculate → `+ - * / %`
- Compare → `== != > < >= <=`
- Condition → `&& || !`
- Assign → `= += -= *= /=`
- Bits → `& | ^ ~`
- Shift → `<< >> >>>`
- Decision → `?:`
