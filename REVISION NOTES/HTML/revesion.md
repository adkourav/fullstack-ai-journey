# HTML - Quick Revision Notes

## 1. Short and Simple Definition
HTML stands for HyperText Markup Language. It is used to create the structure of a web page.

## 2. Types and Their Definitions

### 1) Tags
Tags are keywords written inside angle brackets, used to define elements in HTML.

Use case: Create a heading or paragraph.

Syntax:
```html
<h1>Hello</h1>
<p>This is a paragraph.</p>
```

### 2) Elements
An element is a tag with content inside it.

Use case: Display text inside a heading or paragraph.

Syntax:
```html
<p>Welcome to my website</p>
```

### 3) Attributes
Attributes provide extra information to HTML elements.

Use case: Add a link or image source.

Syntax:
```html
<a href="https://example.com">Visit Website</a>
<img src="photo.jpg" alt="My Photo">
```

### 4) Block Elements
Block elements start on a new line and take full width.

Use case: Create a section or heading.

Syntax:
```html
<div>
  <h1>My Website</h1>
</div>
```

### 5) Inline Elements
Inline elements stay in the same line and are used inside text.

Use case: Highlight a word inside a paragraph.

Syntax:
```html
<p>Hello <span>World</span></p>
```

## 3. Use Cases
- Create headings and paragraphs
- Add links and images
- Build forms and buttons
- Structure a webpage
- Organize content using sections and divs

## 4. Syntax

### Basic HTML structure
```html
<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>
  <h1>Hello</h1>
  <p>Welcome to my website.</p>
</body>
</html>
```

### Link
```html
<a href="https://example.com">Click here</a>
```

### Image
```html
<img src="image.jpg" alt="Image">
```

### Comment
```html
<!-- This is a comment -->
```

## 5. Real-Life Example
A website is like a house:
- HTML = structure of the house
- CSS = decoration of the house
- JavaScript = working parts of the house

Example:
```html
<h1>My Portfolio</h1>
<p>I am a web developer.</p>
<a href="https://google.com">Open Google</a>
```

## Quick Revision Points
- HTML = structure of a webpage
- Tags define elements
- Attributes add extra information
- `<head>` contains page information
- `<body>` contains visible content
- `<div>` is block-level, `<span>` is inline

## Important Things to Remember
- HTML is not a programming language
- HTML is used for structure, not logic
- Always close tags properly
- `<!DOCTYPE html>` tells the browser this is HTML5
